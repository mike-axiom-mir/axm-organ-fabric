# Platform Text Fabric organ intake

Source-preserving intake of the committed Text Fabric organ descriptor family from the pinned Collaboration Platform revision.

These are real donor organ bodies as committed by the donor: structured organ descriptors plus their organ map and provenance/validation context. This intake does **not** upgrade them into independently executable organs if the donor did not provide an independent execution body at this boundary.

`index.js` supplies caller-neutral discovery by `id` and optional `version`; it does not grant authority or rewrite donor state.
