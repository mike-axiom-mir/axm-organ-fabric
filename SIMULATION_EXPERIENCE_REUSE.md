## First useful experiment

Choose one executable package and one host-visible gap. Supply an explicit host
adapter, typed inputs, measurable outcome, fixed resource budget and an
unmodified baseline. Compare one bounded candidate variation on seeded cases,
then retest on unused inputs and in the actual host.

Retain the complete candidate package, source/license identity, interface
contract, dependencies, failed cases and receiver evidence. A useful reusable
organ must do something in the host; an anatomy description or a passing package
lookup is not execution. If no suitable adapter exists, building that adapter is
the first missing capability.

## What may grow

The deterministic route can accumulate tested repairs and reusable compositions.
A neural host may additionally retain learned selection state. Neither requires
the Fabric to own the host, the neural learner or the world simulator.

This note does not implement an Organ Factory, convert descriptive organs into
working packages, alter archived donor bytes, or change the paused platform.
Read-only preserved platform intake is historical provenance, not a mandate to
resume its development.
